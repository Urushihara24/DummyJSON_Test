
## Реализованные проверки

### Auth (4 теста):
- Успешная авторизация (POST /auth/login)
- Неуспешная авторизация с неверным паролем (401)
- Получение профиля по токену (GET /auth/me)
- Получение профиля без токена (401)

### Carts (6 тестов):
- Получение корзин пользователя (GET /carts/user/{userId})
- Получение корзины по ID (GET /carts/{cartId})
- Создание корзины (POST /carts/add)
- Обновление корзины (PUT /carts/{cartId})
- Удаление корзины (DELETE /carts/{cartId})
- Негативный тест: несуществующая корзина (404)

## Особенности реализации

- API DummyJSON является фейковым (in-memory database)
- При DELETE корзина помечается как `isDeleted: true`
- При PUT используется параметр `merge: true` для слияния товаров
- Тесты не зависят друг от друга (кроме фикстуры получения токена)
